# real100 panel

100 diverse RCSB complexes (resolution ≤2.5Å, MW 150-600 Da, non-redundant targets).

Selected and validated by `scripts/generate_real100_config.py`; each entry is referenced
by `configs/diffsbdd_real100.yaml` and `configs/pocket2mol_real100.yaml`
(`pdb` / `full_pdb` paths). Rebuild or refresh the panel by re-running that script.
