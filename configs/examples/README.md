# Example configs

Use these for smoke tests and for wiring your own model before scaling up.

- **`smoke.yaml`** — mock model, three pockets, fast CI / local sanity check.
- **`diffsbdd.example.yaml`** / **`pocket2mol.example.yaml`** — templates for real backends (edit `model.*` paths).
- **`real5.yaml`** / **`real5_quick.yaml`** — small CrossDock-style panels.
- **`real_crossdock5.template.yaml`** — starting point for your own pocket list.
